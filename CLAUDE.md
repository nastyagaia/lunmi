# Lunmi — сайт магазина корейской косметики

Настоящий магазин дизайнера Анастасии (Насти), не просто портфолио. Код — вёрстка макетов из Figma, сайт живёт на Vercel.
Этот файл — паспорт проекта для любого ИИ-помощника (Claude, Codex и др.): прочитай его целиком перед работой.

- Figma: файл Lunmi, fileKey `6KDAnSlaihXgYDLcz39tJZ`, страница main page (`0:1`), дизайн-система в секции UI KIT (`5437:40894`).
- Стек: Next.js (App Router) + Tailwind CSS v4. Бэкенда нет: данные лежат в `src/data/`.

## Как общаться с Анастасией

Анастасия — дизайнер, это её первый сайт в коде. Она хорошо знает Figma, но не разбирается в программировании.
- Объясняй всё простыми словами, по шагам, без жаргона. Если без термина не обойтись — сразу поясни его одной фразой.
- Перед тем как что-то делать, коротко скажи, что и зачем сделаешь. После — что изменилось и где это увидеть.
- Если нужно действие с её стороны (нажать кнопку, установить программу, разрешить доступ) — пиши точно, куда нажать.
- Пиши по-русски, дружелюбно и без спешки. Вопросы «что это значит?» — нормальные, отвечай подробно.

## Где что лежит

- `src/app/globals.css` — токены из Figma (цвета, радиусы, тени) и текстовые стили `text-h1…text-h4`, `text-base-m/s/xs`, `text-caps`. Главный источник правды по стилям.
- `src/app/fonts.css` + `public/fonts/` — шрифты. Unbounded — заголовки, Albert Sans — текст (кириллица и ₽ — из Onest, у Albert Sans их нет).
- `src/components/` — компоненты из UI KIT: `ui.tsx` (Button, SectionHeader, Tag, TextField, Radio, Checkbox, InfoCard, RadioCard…), `Search` (один поиск на всё), `ProductCard`, `Carousel`, `Header` + `HeaderMenus` (город, профиль), `SearchPanel`, `CatalogGrid`/`CatalogSection`, `Cart`, `Checkout` + `CheckoutDrawers` + `Drawer` + `MapView`, `Favorites`, `icons.tsx`.
- `src/data/` — товары и тексты: `sections.ts` (все товары и разделы), `face-care.json` + `catalog-extra.json` (товары), `product-texts.json` (тексты вкладок), `products.ts` (страница товара), `brands.ts`, `menu.ts`, `home.ts`, `pickup-points.ts` (ДЕМО пунктов СДЭК), `cities.ts`, `covers.json`.
- `public/img/` — картинки webp: `face/` и `catalog/` — фото товаров (готовы, с точным фоном, показываются unoptimized), `covers/` — обложки разделов из Figma.
- `scripts/` — импорт фото и данных из папки «lunmi материалы для сайта» на рабочем столе Насти (`import-face-care.mjs`, `import-catalog.mjs` по списку `catalog.extra.mjs`) и текстов из ChatGPT (`import-product-texts.mjs`). Нужны только чтобы добавить/обновить товары; готовый результат уже лежит в репозитории.

## Правила

1. Цвета и шрифты — только через токены из `globals.css`. Нет нужного токена — сначала добавь его туда с пометкой, какой переменной Figma он соответствует.
2. Имена компонентов и вариантов повторяют UI KIT в Figma, чтобы дизайнер и код говорили на одном языке.
3. Вёрстка резиновая: сетка 12 колонок × 96 px через 8 px, контейнер 1240px (`container-page`), поля 100 на 1440; блок на N колонок = 96N + 8(N−1); брейкпоинты Tailwind `sm 640 / md 768 / lg 1024 / xl 1280`. Десктоп сверяется с макетом 1440, мобилка — 390.
4. Картинки — через `next/image` с правильным `sizes`, файлы webp не больше 2x от размера на экране.
5. Перед коммитом: `npm run build` и `npm run lint` без ошибок, скриншоты 1440 / 768 / 390 без горизонтального скролла.
6. Тексты интерфейса — по-русски, с «ёлочками» и длинным тире.

## Состояние проекта (обновлено 4 октября 2026)

Сайт: https://lunmi.vercel.app (Vercel публикует ветку main автоматически после push). Текущая работа — в ветке `draft`
(в main — только когда Настя попросит). Push делает Настя сама через GitHub Desktop.
Запуск локально: `npm install`, затем `npm run dev` → http://localhost:3000.

Сделано:
- Главная (слайдер героя с видео, Bestsellers с «вытягиванием» центральной карточки, каталог-мозаика, бренды, скидки недели, AI-баннер, отзывы, FAQ).
- Каталог: 9 разделов (`/catalog` — уход для лица, `/catalog/<раздел>`), 231 товар с фото, фильтры, подразделы из меню; «Макияж» — 58 товаров с оттенками.
- Страница товара с вкладками: тексты есть у всех товаров (ChatGPT + `scripts/cards/*.json`, конвейер — `scripts/docs-to-cards.py` → `import-product-texts.mjs`); у части макияжа пустые «Состав»/«Характеристики» — временный текст. Отзывы — ЗАГЛУШКА из макета.
- Бренды (`/brands`, `/brands/<бренд>`), Скидки (`/sale`), Поиск (панель в шапке + `/search`), Избранное (`/favorites`), AI-подбор (`/ai`, по правилам, без настоящего AI).
- Корзина (выезжающая панель), оформление `/checkout` по макетам checkout 2 → courier: боковые панели, карта OpenStreetMap (Leaflet, без ключей), пункты СДЭК — ДЕМО-список, оплата — ДЕМО-форма (номер карты не сохраняется, деньги не списываются).
- Шапка: стекло, меню каталога, выбор города, меню профиля, мобильное меню.
- Данные покупателя (корзина, избранное, контакты, адреса, город) хранятся в браузере (localStorage).

Решения:
- Шапка — стекло как у Gentle Monster (`glass` в globals.css). Карта — OpenStreetMap, а не Яндекс (без ключей и платежей).
- Картинки из Figma выгружаются в 2x через временные копии (потом удаляются) и конвертируются в webp; новые файлы — только с уникальными именами.
- Ответы в FAQ и отзывы — временные.

настоящая оплата через платёжный сервис, недостающие вкладки «Состав» у макияжа, подгонка остальных кадров Figma под сетку 8,
