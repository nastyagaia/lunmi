# Lunmi — сайт магазина корейской косметики

Портфолио-проект дизайнера Анастасии. Код — вёрстка макетов из Figma, сайт живёт на Vercel.

- Figma: файл Lunmi, fileKey `6KDAnSlaihXgYDLcz39tJZ`, страница main page (`0:1`), дизайн-система в секции UI KIT (`5437:40894`).
- Стек: Next.js (App Router) + Tailwind CSS v4. Бэкенда нет: данные лежат в `src/data/`.

## Как общаться с Анастасией

Анастасия — дизайнер, это её первый сайт в коде. Она хорошо знает Figma, но не разбирается в программировании.
- Объясняй всё простыми словами, по шагам, без жаргона. Если без термина не обойтись — сразу поясни его одной фразой.
- Перед тем как что-то делать, коротко скажи, что и зачем сделаешь. После — что изменилось и где это увидеть.
- Если нужно действие с её стороны (нажать кнопку, установить программу, разрешить доступ) — пиши точно, куда нажать.
- Пиши по-русски, дружелюбно и без спешки. Вопросы «что это значит?» — нормальные, отвечай подробно.

## Где что лежит

- `src/app/globals.css` — токены из Figma (цвета, радиусы, тени) и текстовые стили `text-h1…text-h4`, `text-base-m/s/xs`, `text-caps`. Главный источник правды по стилям.
- `src/app/fonts.css` + `public/fonts/` — шрифты. Unbounded — заголовки, Albert Sans — текст (кириллица и ₽ — из Onest, у Albert Sans их нет).
- `src/components/` — компоненты из UI KIT: `ui.tsx` (Button, SectionHeader, Tag), `ProductCard`, `Carousel`, `Header`, `Footer`, `icons.tsx`.
- `src/data/` — тексты и товары страниц.
- `public/img/` — картинки, выгруженные из Figma в 2x, формат webp.

## Правила

1. Цвета и шрифты — только через токены из `globals.css`. Нет нужного токена — сначала добавь его туда с пометкой, какой переменной Figma он соответствует.
2. Имена компонентов и вариантов повторяют UI KIT в Figma, чтобы дизайнер и код говорили на одном языке.
3. Вёрстка резиновая: контейнер 1218px (`container-page`), брейкпоинты Tailwind `sm 640 / md 768 / lg 1024 / xl 1280`. Десктоп сверяется с макетом 1440, мобилка — 390.
4. Картинки — через `next/image` с правильным `sizes`, файлы webp не больше 2x от размера на экране.
5. Перед коммитом: `npm run build` и `npm run lint` без ошибок, скриншоты 1440 / 768 / 390 без горизонтального скролла.
6. Тексты интерфейса — по-русски, с «ёлочками» и длинным тире.
