# Lunmi

Сайт интернет-магазина корейской косметики — вёрстка дизайна из Figma.

Next.js + Tailwind CSS. Сайт выкладывается на Vercel автоматически после каждого изменения в этом репозитории.

## Запустить у себя

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

Как устроен проект — в [CLAUDE.md](./CLAUDE.md).
